# DesveladoAP Setup Guide

## Required Software
- Desvelado v1.1.0 (only the [latest Steam release](https://store.steampowered.com/app/2878710/Desvelado/) has been tested)
- Godot Mod Loader (GML) v7.0.1 - [follow the official documentation for download](https://wiki.godotmodding.com/)
- DesveladoAP - Download it from [GitHub releases](https://github.com/JLannoo/JLannoo-DesveladoAP/releases)

## Installation procedure (Windows / Linux through Proton)

1. Download and install the latest version of GML. Follow the official self-setup instructions found in
   [this tutorial](https://wiki.godotmodding.com/guides/integration/mod_loader_self_setup/).
    - When launching the game you should see a popup saying that the mod loader was successfully installed. If not,
      review the step and try again.

2. In the game folder, next to the game executable and the GML ***addons*** folder, create a new folder called ***mods***.

3. Place the **JLannoo-DesveladoAP.zip** file you downloaded inside that folder. There's no need to extract it; just
   placing the .zip inside ***mods*** is enough.

## How to connect to a Multiworld
When opening the game you should now see (if everything was installed correctly) a window appear in-game, along with a
new option called **Archipelago Console** in the main menu and the pause menu.

In the **Archipelago Console**, use the connect menu in the top-right corner to enter the host, port, slot name and
password of the multiworld.  
You can also use the command line at the bottom to use it as a regular text client.
