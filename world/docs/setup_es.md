# Desvelado - Guía de setup

## Software necesario
- Desvelado v1.1.0 (solamente [la última release de Steam](https://store.steampowered.com/app/2878710/Desvelado/) fue testeada)
- Godot Mod Loader (GML) v7.0.1 - [seguir la documentación oficial para la descarga](https://wiki.godotmodding.com/)
- DesveladoAP - Descargar desde [las releases de GitHub](https://github.com/JLannoo/JLannoo-DesveladoAP/releases)

## Procedimiento de instalación (Windows / Linux a través de Proton)

1. Descargar e instalar la versión más reciente de GML. Seguir la guía oficial de self-setup en
   [este tutorial](https://wiki.godotmodding.com/guides/integration/mod_loader_self_setup/).
    - Una vez que ejecutes el juego deberías ver un popup diciendo que el mod loader se instaló correctamente. Si no lo
      ves, revisá los pasos anteriores y volvé a probar.

2. En la carpeta del juego, junto al ejecutable y a la carpeta ***addons*** de GML, crear una nueva carpeta llamada
   ***mods***.

3. Dentro de esa carpeta colocar el archivo **JLannoo-DesveladoAP.zip** descargado previamente. No es necesario
   extraerlo, con solo ponerlo ahí alcanza.

## Cómo conectarse a un Multiworld
Cuando abras el juego deberías ver (si todo salió bien) aparecer una ventana y una nueva opción **Archipelago Console**
en el menú principal y en el menú de pausa.

En la ventana **Archipelago Console** podés usar el menú de conexión arriba a la derecha para completar el host,
puerto, nombre de slot y contraseña del Multiworld.  
Además, podés usar el campo de texto de abajo de todo para usar la ventana como un cliente de texto normal.
